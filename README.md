# IT Helpdesk Support Portal
Responsive multi-page demo website made with HTML, CSS and JavaScript.

## Pages
- `index.html` — Home
- `ticket.html` — Raise Ticket
- `services.html` — Services
- `knowledge.html` — Knowledge Base
- `contact.html` — Contact

## Run locally
Open `index.html` in a browser or use VS Code Live Server.

## Deploy on GitHub Pages
1. Upload all files and folders to the repository root.
2. Keep `index.html` in the root; GitHub Pages uses it as the default page.
3. Open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
4. Check **Actions** until the Pages workflow succeeds.
5. Open the website URL shown in Settings → Pages.

## Important
Ticket and contact forms are demos. They store submissions in browser local storage only; they do not send emails or save centrally. A production site needs a secure backend/API.
